关于 NPA

Node Proxy Agent · Phase 1 Core

NPA 是面向开发、测试、运维和 AI Agent 的轻量级局域网节点访问工具。一期提供 SSH、SFTP、隧道、Web 管理、MCP、Capability 权限和审计能力。

固定端口：Web 127.0.0.1:56700，MCP 127.0.0.1:56701。默认只监听回环接口。

架构遵循 SRS v2.1 与 SAD：单进程、单二进制、成熟协议优先、MCP 高风险能力默认关闭。
