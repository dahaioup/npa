通道

SSH 隧道与 NPA 端口映射统一管理 · 监听 → 经由 → 目标

三种转发：本地端口转发＝本机监听 → 经由节点 → 远程服务（走 NPA 数据面，链路里没有 SSH 服务即 NPA 通道）；远程端口转发＝远程机器监听 → 本地服务（走 SSH 反向隧道，远程服务须是 SSH 服务）；动态端口转发＝本机 SOCKS 代理 → SSH 服务。链路里有 SSH 节点即 SSH 通道，否则是 NPA 通道。

仓库：—插件管理器：—
插件管理器是 NPA 的内置能力：随 core 编译、始终可用、不可停用，也不可卸载。它负责读取仓库索引 registry.json、下载产物、校验 sha256、解压并落盘；NPA 只做转发与鉴权。仓库里的 npa-plugin-manager 是可选的外部覆盖实现（独立插件进程，走标准插件协议 stdio JSON-RPC）——装了由外部进程接管，卸掉内置实现立刻顶上。下载与安装会写入审计日志。

关于 NPA

节点代理 · 三期网络

NPA 是面向开发、测试、运维和 AI Agent 的轻量级局域网节点访问工具。当前包含核心程序、桌面插件运行时与网络拓扑基础能力。

固定端口：Web 127.0.0.1:56700，MCP 127.0.0.1:56701；节点发现使用标准 mDNS 5353/UDP，不占用 NPA 私有端口。

架构遵循 SRS v2.1 与 SAD：单进程、单二进制、成熟协议优先、MCP 高风险能力默认关闭、发现不等于信任。

专用名词解释
MCP
Model Context Protocol，模型上下文协议，用于 AI 客户端调用工具服务。
SSH
Secure Shell，安全壳网络协议，用于安全登录和执行命令。
SFTP
SSH File Transfer Protocol，基于 SSH 的文件传输协议。
PTY
Pseudo Terminal，伪终端，网页终端会话使用的虚拟终端。
mDNS
Multicast DNS，多播域名服务，用于局域网节点发现。
DNS-SD
DNS Service Discovery，基于 DNS 的服务发现。
Relay
中继，通过已授权节点转发访问其可达子网。
Capability
能力权限，控制 MCP 可以调用哪一类功能。
