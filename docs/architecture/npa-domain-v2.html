选举规则
探测图 → 连通分量；分量内 (uptime, nodeID) 序 + 抖动选主；跨域成员优先（如 B1）。管理者失联 3×20s，成员本地重选，缓存的成员表零信息损失。
活性判定
请求即活：20s 拉取 = 心跳。管理者记录 last_seen + 状态变化时间（增量依据）；60s 未拉取判离线。数据面调用成功同样刷新活性。
三平面分离：控制 / 流式 / 批量 核心修复：批量流量不再与 exec / pty / fs 抢通道池

通道池（现有，修复后）internal/peer/hub.go · take()

只承载小数据流：exec 结果、PTY、SFTP 会话、反向 TCP。池子从此不再被大文件吸干。

问题（现状）修复
一用即毁：通道结束 conn.Close() 不归还，靠 agent 慢慢补传输结束归还池（校验帧边界后复用），池枯时 临时扩拨专用连接而非报错
take 等 5s 后直接失败（50ms 轮询 × 100）池空 → 触发 agent 立即补拨 + 请求排队；条件变量替代轮询
帧碎片化：WSConn 每次写一个帧，SFTP 小包打碎吞吐写缓冲聚合（64KB 或 5ms），maxFrameSize=4MB 上限不变
数据连接无 keepalive，NAT 静默断流通道级 ping/pong + 中途断流向上报（不再无限悬挂）

批量文件面（新增）file.go · 上传 / 下载 / 升级包

大文件专用路径，两档按可达性自动选择，与通道池完全隔离。

档位机制
A · 直连 HTTP
同 / 可达网段（最常见）		上级签发一次性 /api/file/{token}（5min、用后即焚，语义同现有 /download/{token}）→ 节点 56701 纯 HTTP 传输。Range 续传、分块 SHA256、吞吐即 HTTP 吞吐。
B · 反向 bulk 通道
不可直连（NAT 后）		反向链路上新增 TypeBulk：不占池，按需临时拨出站连接，传完即关；块大小 1MB + 逐块校验 + 断点续传。
升级包推送（现走 SFTP-over-WS，十几 MB 塞通道 → 推送失败主因）改走文件面 A/B；落地后复用现有一次性 /download/{token} + 自升级脚本；重启前 drain：停接新会话，在途调用结束后再替换二进制。
限额与公平每节点并发 bulk ≤2、全局限速（设置项）、审计记录字节数；防止 bulk 反过来挤占上行带宽影响控制面。
状态与协议细节

域内状态同步（20s）

GET /api/domain/state?since=seq · 成员凭证
返回 delta：[成员变更 / 活性翻转 / 版本号]；since 过旧 → 全量快照
每域单调 (epoch, seq)；epoch 在管理者重选时 +1，防旧管理者复活后发陈旧 delta
拓扑更新必须带 HMAC(token) 签名：管理者是下发"该连谁"的最高价值攻击面，成员拒收无签名 / 低 epoch 更新
  • 状态条目标观察者：本域实测 last_seen / probe 结果 vs 邻域转述（转述标 stale）
  • 节点缓存成员表：重选 / 全量重同步零信息损失

域间联系（管理者长连接）

push 为主：状态一变，delta 推给所有邻域管理者（O(域数) 条消息，非 20s 轮询）
pull 兜底：新邻域出现 / seq 断档 / 连接重建 → 全量快照
跨域访问复用现有原语：require（通知对方直连）→ 不通则 relay_open（管理者代理）——协议一套，直连与代理只是两档
交叉节点（如 B1）一节点持多域管理者身份，两域间零新建连接
  • 两个交叉节点并存时按 (uptime, nodeID) 唯一化，防双主脑裂

隧道稳定性（现状修复）

重连退避现有 1s→30s 封顶（internal/tunnel/manager.go:167），保留
增加成功计数才重置退避（防振荡链路 1s 疯狂重试）
隧道健康探针：每条隧道周期性端到端探活（真实连一次目标），失败计入状态字段并在 UI 标红，而不是静默半开
WS ReadHeaderTimeout=10s 已有；补 IdleTimeout 与 goroutine panic recover（41 处 go func 现无一保护，进程级脆弱）
  • 推升级失败 = 通道饥饿 + SFTP-over-WS 慢的复合症状；文件面落地后复发率应趋零
针对"通信不稳定 / 推送失败 / 隧道异常"的最小修复清单（不分域也可立即做）

① 通道池归还 + 空池扩拨

收益最大的一处。现状每条通道用完即毁、池枯 5s 报错；改为归还复用 + 按需临时扩拨，exec/pty 不再被大文件饿死。hub.go take()/pop()

② 升级包改走文件面

十几 MB 二进制不再塞 SFTP-over-WS；直连走 HTTP，不可直连走 TypeBulk。推送失败与超时随之消失。push.go PushPackage()

③ WSConn 写缓冲 + 通道 keepalive

64KB/5ms 聚合写消除帧碎片；通道级 ping/pong 让 NAT 断流在秒级暴露为显式错误，而非悬挂到超时。wsconn.go

④ goroutine panic recover

41 处裸 go func、全库零 recover：任一 nil map 即全进程退出、所有隧道中断。safeGo + HTTP recover 中间件，半天工作量。

⑤ 隧道端到端探活

半开隧道（本端在、对端死）现在无感知；周期真实探活 + 状态字段 + UI 标红，把"隧道异常"从用户投诉变成可观测指标。

⑥ 传输中断点续传

bulk 面分块 + 逐块 SHA256 + Range 续传；大文件不再"断一次从头来"，弱网体验质变。
