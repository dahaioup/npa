02编排层Service

唯一的应用服务 internal/service/service.go · 1299 行

业务编排

  • 节点：增删改、健康探测、本地 / SSH / peer 三种寻址
  • 命令、终端、文件、隧道、端口映射、Relay、拓扑
  • 设置热生效、更新检查 / 准备 / 推送、概览、审计查询

横切面（MCP 硬门槛）

  • policy.Check：仅 SourceMCP 校验 Capability，Web 本地管理不受限
  • 速率限制：固定窗口，按操作计数

  • state.Open → service.New 装配 → MCP / Web / Peer
  • 恢复隧道与端口映射、启动 mDNS 与 Plugin
  • Ctrl+C / Web「退出」同一条 5s 优雅关闭路径
▼每个能力是一个独立 Manager，通过 Repository 接口只依赖 Store
03能力层Managers

九个能力管理器 + 三组系统集成 能力可单独开关、单独审计

SSH Manager internal/ssh

  • x/crypto/ssh；TOFU 指纹、密钥 / 口令 / Agent
  • 连接复用、Exec、交互 Shell（PTY）
  • 数据面：direct-tcpip / forwarded-tcpip

File Service internal/file

  • pkg/sftp：列目录 / 读 / 写 / 上传 / 下载 / 改名
  • 寻址透明：SSH 节点走 SFTP，peer 节点走 WS 上的 SFTP

Tunnel internal/tunnel

  • Local / Remote / SOCKS5，KeepAlive
  • 定义持久化，启动时按设置自动恢复

Port Mapping internal/portmap

  • 本机监听 → 目标 IP:port，默认仅 127.0.0.1
  • 转发路径自动选择：直连，否则经 Relay / 反向链路

Relay internal/relay

  • 选路：直连优先 → 已信任且启用的健康节点单跳
  • 数据面仍是 SSH / peer 通道，不自造协议

Discovery internal/discovery

  • mDNS/DNS-SD _npa._tcp.local.，5353/UDP
  • TXT：ID / 版本 / 入口 / 能力 / 可达子网；6h 清理陈旧记录

Peer（Hub + Agent） internal/peer

  • Hub：注册、控制长连接、空闲连接池、跨上级协调
  • Agent：种子 / mDNS / 网段探测 → /api/info 校验 → 注册、心跳、退避
  • 通道首帧：open · exec · pty · fs · relay_open

Desktop + Plugin internal/desktop · internal/plugin

  • JSON-RPC 2.0 + Content-Length + stdio 子进程
  • 插件优先，缺失 / 异常时回退内置脚本；截图 / 鼠标独立授权

系统集成 selfupdate · autostart · console · version

  • 自更新：下载 zip → 解包校验 → 替换二进制并重启
  • 开机自启：注册表 / LaunchAgent / systemd / XDG
  • 隐藏控制台、日志轮转、语义化版本比较
▼所有 Manager 通过 Repository 接口读写同一个 Store；凭据只在 Store 内解密
04基础设施State

无配置文件：状态、凭据、审计都在本地数据目录 ~/.npa（可用 --data-dir 覆盖）

Store bbolt

  • settings / nodes / tunnels / port mappings
  • discovered / relay routes / audit

凭据 AES-GCM

  • master.key 独立存放
  • 密文入库，不写日志、不回显

审计 + 日志 slog

  • 结构化事件脱敏，保留 N 天
  • npa.log 10MB 轮转；可选隐藏控制台

共享内核 model · errors

  • 统一数据模型与 JSON 形状
  • 错误码 → HTTP 状态 / MCP 错误

固定端口

56700 Web 管理面仅 127.0.0.1，不随设置放开
56701 Mesh（MCP + Peer）范围 = mcp_bind_scope ∪ peer_bind_scope
5353 mDNS / DNS-SDUDP，标准端口，不占用私有端口
56710 旧版兼容值已不再监听，发现侧归一为 56701

数据面（不自造协议栈）

SSH
direct-tcpip / forwarded-tcpip，x/crypto/ssh
SFTP
SSH 节点保留；peer 节点降级为回退（优先 /api/file/* 纯 HTTP）
Peer
WS 首帧声明通道：open / exec / pty / fs / relay_open；直连失败可经持有上级代理
HTTP
/proxy/{id}/ 受控反代；节点文件面 /api/file/* 与执行面 /api/exec；跨域兜底 peer_relay_fallback
单跳 Relay NPA 映射 + SSH 映射串联 跨域 A→B→N 代理（e2e 已验证）

关键设计取舍

  • 单进程承载控制面与全部数据面，故障域单一
  • 反向接入：连接永远由下级发起，上级零入站
  • 发现 ≠ 信任：mDNS 只提供候选，注册后仍可探测健康
  • 端口收敛：MCP 与节点通信合并到 56701，按路径分发
  • 能力分层：MCP 高风险能力独立开关；Web 本地管理不受限

与文档不一致（实现为准）

  • 默认值实际为能力全开、mesh 监听 lan（调试期），与 README「默认只注册 nodes.list / 回环」不符
  • SAD 仍写 MCP 独占 56701、无 peer；实际 56701 与 peer 共用
  • README 称节点页无手工添加入口，但 UI 已有添加表单
