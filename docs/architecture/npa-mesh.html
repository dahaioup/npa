执行面

  • exec：非交互命令，capture stdout/stderr
  • pty：交互终端（x/crypto/ssh）
  • fs：SFTP over WS（pkg/sftp 走管道，不起 sshd）
  • open：任意 TCP（SSH / HTTP / 数据库）
出站只发起出站连接；即使主机在 NAT 后、没有端口映射，也能被上级调用。
① 发现与注册（B 发起）

② 控制长连接（双向）
心跳 ping / pong · 控制帧 {type: exec | pty | fs}
③ 数据面（复用同一条连接）
反向 TCP {type: open} · 中继 {type: relay_open} · 双向字节流

跨上级：目标在两跳之外时，仍然逐跳走已有反向链路

A 只认识 B；B 同时是 N 的上级。A 需要访问 N 时，A 请 B 去要一条到 N 的转发。

STEP 01

MCP 调用

Streamable HTTP 到 /mcp，上下文打上 SourceMCP。

STEP 02

策略与限流

关闭 SSH 能力时在此直接拒绝；固定窗口计数超限即失败。

STEP 03

寻址

同一台机器 → 本地；SSH 节点 → 直连；peer 节点 → 走链路。

STEP 04

取链路

Hub 从空闲池挑一条；没有则临时拨号或向上级 require。

STEP 05

执行

写一帧 {type:"exec"}；B 跑完把 stdout / 退出码回传。

STEP 06

审计

audit.Record 统一脱敏，成功与失败都留痕。
